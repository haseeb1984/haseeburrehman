AI SEO Bot
Automated, page-aware WordPress SEO metadata

Working automation foundation · deployment and enhancements in progress

A scheduled SEO assistant that reads published WordPress content, prepares contextual metadata and updates supported AIOSEO fields through an authenticated endpoint.

Explore product / source ↗Discuss a demo or licence ↗

Capabilities & workflows

Documented functionality: Scheduled or manually triggered GitHub Actions runs; WordPress REST content retrieval; page-aware AI title/description/keyword suggestions; structured response validation; authenticated custom endpoint; supported AIOSEO metadata updates and run logs.

In-progress / client delivery scope: Select and consolidate the canonical runner, configure secure WordPress and AI-provider credentials, validate metadata updates on staging content, tune schedules and retries, and complete the target site's authenticated endpoint setup.

Product scope

Requires WordPress credentials, a configured AI provider and the custom endpoint on the target site. The repository documents overlapping runner variants; select one canonical workflow before scheduling to avoid duplicate writes.

Technology

Python · WordPress REST API · AI provider · GitHub Actions

Who it can help

WordPress publishers, site owners and SEO teams that want to generate contextual metadata suggestions and manage supported AIOSEO fields through a controlled, authenticated workflow.

In progress & delivery roadmap: Multi-site administration, additional SEO plugin support, richer content-quality checks, configurable approval steps and expanded reporting can be added against the client's WordPress estate. The product page presents current foundations alongside work that can be completed with a client. Final scope, dependencies, milestones and acceptance criteria are agreed before implementation; no unfinished integration is represented as already production-ready.
