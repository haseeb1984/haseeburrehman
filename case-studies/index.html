CASE STUDY 01 / INDEPENDENT PRODUCT

PulseDrift — self-healing API gateway

Integration resilience starts with recognising that upstream contracts change. PulseDrift is an engineering project focused on detecting and repairing schema drift in real time to reduce integration downtime.

Problem space

API consumers can fail when upstream payload structures evolve unexpectedly. Retries alone do not resolve incompatible schemas and can amplify operational noise.

Engineering focus

Schema drift detection and repair, resilient request handling, idempotent request caching and dead-letter queue event replay.

Intended outcome

Protect dependent integrations from avoidable downtime and provide a controlled recovery path when message or contract processing fails.

Project status

Independent product/repository with a companion mock environment. This portfolio describes the intended system capabilities; it does not claim independently measured production outcomes.

CASE STUDY 02 / ENTERPRISE INTEGRATION

Global attendance & biometric integration engine

Cross-platform integration connecting Hikvision and eSSL biometric devices with Zoho People. The solution addressed the gap between physical attendance capture and HR policy processing.

Scope

Attendance and leave data, roster rules, work-from-home scenarios, salary deduction logic and reporting.

Approach

Modular .NET/PHP applications and API-based communication between biometric devices and Zoho People.
